## 📚 Projects

### 🏠 **1. House Price Prediction**

A Machine Learning project that predicts the **price of a house** based on different features such as area, number of bedrooms, bathrooms, location-related information, and other property details.

#### 🎯 Objective

The main objective of this project is to:

* Understand **Regression in Machine Learning**
* Perform **Data Preprocessing**
* Perform **Exploratory Data Analysis (EDA)**
* Select useful features
* Train a **Linear Regression Model**
* Evaluate model performance
* Predict house prices for new data

#### 🧠 Algorithm Used

**Linear Regression**

Linear Regression is a **Supervised Machine Learning Algorithm** used to predict continuous numerical values.

**Input → House Features**

**Output → Predicted House Price**

#### 🛠️ Technologies & Libraries

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

#### 🔄 Workflow

```text
Dataset
   ↓
Data Cleaning
   ↓
Data Preprocessing
   ↓
Exploratory Data Analysis (EDA)
   ↓
Feature Selection
   ↓
Train-Test Split
   ↓
Linear Regression
   ↓
Model Evaluation
   ↓
House Price Prediction
```

#### 📊 Evaluation Metrics

* **Mean Absolute Error (MAE)**
* **Mean Squared Error (MSE)**
* **R² Score**

### 🎓 **2. Placement Predictor**

A Machine Learning project that predicts whether a student is likely to be **Placed or Not Placed** based on student-related information.

This project demonstrates the basic Machine Learning workflow including **data preprocessing, data analysis, model training, model evaluation, prediction, and deployment using Flask**.

#### 🎯 Objective

The main objective of this project is to build a **Machine Learning model** that can predict student placement outcomes using historical placement data.

#### 🛠️ Technologies & Libraries

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook
* Flask

#### 🔄 Workflow

```text
Dataset
   ↓
Data Preprocessing
   ↓
Data Analysis
   ↓
Model Training
   ↓
Model Evaluation
   ↓
Placement Prediction
   ↓
Flask Deployment
```

#### 📂 Project Files

```text
Placement_Predictor/
│
├── app.py
├── model.pkl
├── students_placement.csv
├── prediction_history.csv
├── requirements.txt
├── student-placement-predictor.ipynb
└── README.md
```

#### 🚀 How to Run

**1. Clone the repository**

```bash
git clone https://github.com/Sandbhor12/Machine-Learning_Projects.git
```

**2. Navigate to the project**

```bash
cd Machine-Learning_Projects/Placement_Predictor
```

**3. Install required libraries**

```bash
pip install -r requirements.txt
```

**4. Run the Flask application**

```bash
python app.py
```

**5. Open in browser**

```text
http://127.0.0.1:5000/
```

#### 📈 Result

The trained Machine Learning model predicts whether a student is likely to be:

**Placed ✅**

or

**Not Placed ❌**

based on the given input data.
